# PicoSynth-DS
ICO SYNTH DS - A Simple PSG Synthesizer Homebrew for NDS

Description:
Hi everyone! I created a simple synthesizer homebrew for the Nintendo DS called PICO SYNTH DS, built using devkitPRO (C/C++).
It utilizes the Nintendo DS internal PSG engine to generate classic chiptune sounds.
Features:
• Engine: Nintendo DS internal PSG (Square / Pulse wave)
• Touch Controls: Playable on-screen keyboard
• Hardware Controls:
	• L / R Buttons: Change Octave
	• Left / Right D-pad: Adjust Duty Cycle (e.g., 12.5%, 25%, 37.5%, 50%)
	• Up / Down D-pad: Adjust Volume
